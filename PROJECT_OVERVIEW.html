Project Handoff & Architectural Reference

This project is a high-performance, production-ready B2B web application for Bilal Decor Studio (Marquee Ceilings & Stage Chadar Manufacturer in Lahore & Gujranwala, Pakistan). It is specifically configured for seamless migration to another Antigravity account or developer instance.

1. Business Model & Strict Language Standard

Business Model:

Wholesale B2B manufacturing of Stage Chadrein (Stage Ceilings), Main Hall Ceilings, and Rahdari Canopies sold per square foot (Length × Width) to marquee decorators across Pakistan.

Strict Language Policy:

100% Everyday Roman Urdu. No raw English sentences for user UI, and no difficult literary Urdu words (avoid "Markazi Page", "Fi Murabba Foot"). Use common terms: "Home Page", "Designs aur Rates", "Kul Bill".

2. Technology Stack & Zero-Dependency Architecture

Module Technology Role
Backend Server Node.js Built-ins (http, fs, path, crypto) Zero npm dependencies. Runs on any Node 16+ instance.
Security Engine PBKDF2 SHA-512 + Salt (10,000 rounds) Server-side password hashing & 15m anti-brute-force rate limiting.
AI Estimator assets/js/ai_scheduler.js Calculates factory production duration and calendar dispatch dates.
3D Tactile UX popup.js + tilt3d.js + style.css In-app 3D modal alerts (no browser alerts) & card mouse perspective.
Data & Reports Chart.js + SheetJS + html2pdf.js Sales graphs, native Excel (.XLSX) export, and PDF invoices.

3. BDS Smart AI Delivery Rules

1.

Base Duration: 5 to 6 working days (Standard for 1 to 3 chadrein).

2.

Volume Rule (>3 Chadrein): Each additional chadar adds +1 working day (e.g. 4 sets = 6-7 days, 5 sets = 7-8 days).

3.

Factory Queue Rush: If active factory queue has ≥ 5 orders, adds +2 days per batch of 5 queued jobs.

4.

Fabric Area Factor: Fabrics > 2,500 sq ft add +1 day; > 5,000 sq ft add +2 days for multi-seam pleating and QC.

5.

Calendar Dispatch Date: Automatically skips Sundays and calculates clean formatted dispatch dates (e.g. 28 Nov 2026).

4. Enterprise Security Specifications

PBKDF2 SHA-512

10,000 iterations with cryptographically random salt. Zero passwords in client code.

Anti-Brute-Force

5 failed password attempts locks client IP for 15 minutes with remaining attempt counter.

Bearer Token Auth

64-character hex session token protects customer data and CSV exports behind HTTP 401.
